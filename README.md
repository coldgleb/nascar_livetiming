# NASCAR Лайв-тайминг 🏁

Лёгкая веб-страница с живым табло гонок NASCAR: позиции, интервалы, время круга,
флаг, стадия и детали по каждому гонщику. Обновляется автоматически каждые ~2 секунды.
Полностью адаптирована под телефоны.

Данные берутся напрямую из публичного фида NASCAR
(`https://cf.nascar.com/live/feeds/live-feed.json`) — **бэкенд не нужен**, это просто
статические файлы (HTML + CSS + JS без зависимостей и сборки).

## Файлы
- `index.html` — разметка
- `styles.css` — оформление и адаптив
- `app.js` — загрузка фида и рендер

## Запуск локально
Проще всего — поднять локальный сервер (открытие через `file://` тоже работает,
т.к. у фида открыт CORS, но сервер надёжнее):

```bash
cd nascar_livetiming
python3 -m http.server 8000
```

Затем открыть http://localhost:8000 в браузере.

## Когда нет гонки
Фид отдаёт данные только во время активной сессии (практика / квалификация / гонка).
Если сессии нет, страница покажет сообщение и кнопку **«Показать демо»** — она выведет
образец табло, чтобы посмотреть, как всё выглядит.

## Деплой на GitHub Pages
1. Создать репозиторий и запушить эти файлы:
   ```bash
   git init
   git add .
   git commit -m "NASCAR live timing"
   git branch -M main
   git remote add origin <ваш-репозиторий>
   git push -u origin main
   ```
2. В настройках репозитория: **Settings → Pages → Source → Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Открыть выданный URL (`https://<user>.github.io/<repo>/`) — в т.ч. с телефона.

Страница работает по HTTPS, фид тоже HTTPS с открытым CORS, поэтому всё грузится
напрямую из браузера.

## Заметки про данные
- `flag_state`: 1 — зелёный, 2 — кошн (жёлтый), 3 — красный, 4 — финиш, 8 — прогрев.
- `series_id`: 1 — Cup, 2 — Xfinity, 3 — Trucks.
- Поля читаются защитно: если чего-то нет в фиде, показывается «—».
